Private prepaid payments for AI and API usage. Fund an anonymous note with ETH, pay per request behind a zero-knowledge proof, withdraw the rest anytime. No cards, no accounts, no tracking.

### What we build

- [openzk.app](https://openzk.app): the product, anonymous prepaid compute that runs entirely in the browser
- [@openzk.app/purse](https://www.npmjs.com/package/@openzk.app/purse): React toolkit for the zkAPI protocol
- [purse](https://github.com/openzkapp/purse): source for the toolkit, MIT licensed
